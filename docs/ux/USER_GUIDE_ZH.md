# MH 云存档同步使用指南（中文 Alpha）

## 这是什么

MH Save Sync 用来解决“办公室 Mac 玩一段，回家 Android 继续玩”的存档同步问题。Mac 和 Android 都连接到同一个服务器；服务器只保存加密后的存档快照，不保存恢复密钥或明文存档。

当前仍是 Alpha：可以用于验证流程和自部署，但不要把它当作唯一备份。保留原始模拟器存档和额外备份仍然是底线。

## 第一次设置

### 1. 先确认服务器地址

Mac 和 Android 必须填同一个服务器地址，例如：

```text
http://8.130.112.207:39082
```

这个地址只给客户端使用；对象存储管理端口、数据库端口和管理员端口都不要填进 App。

### 2. Mac 端

```bash
./scripts/install-macos-app.sh
open "/Applications/MH Save Sync.app"
```

打开后它是菜单栏 App，不会常驻 Dock。请看屏幕右上角的 **MH 云存档 · 设服务器/选目录/选密钥/就绪**。

菜单顶部会一直显示 **同步路线：MH3G / macOS Nemessix → 本机安全缓存 → 服务器地址** 和 **下一步：……**。如果你只配置了服务器地址，它会继续提示你选择 Mac 存档目录和恢复密钥文件，不会让“同步到哪里了”变成黑盒。

菜单里按顺序先点：

1. **打开同步向导（告诉我下一步）**：任何时候不确定下一步，就先点这个。
2. **设置服务器地址…**：填和 Android 一样的服务器地址。
3. **选择 Mac Nemessix 存档目录…**：选择 MH3G 的 `data/00000001` 存档目录或该逻辑存档根目录。
4. **生成恢复密钥文件**（推荐）或 **选择恢复密钥文件…**：没有可用文件时直接生成；已有文件时选择 `~/Documents/Secrets` 下的 64 位 hex 文件；App 只保存路径，不保存密钥内容。
5. **启动前检查**：每次打开 MH3G 前先点一次。
6. **立即上传 Mac 存档到服务器**：手动上传；会显示服务器地址、云端版本和是否保留了冲突分支。
7. **我已退出 MH3G：立即对账上传**：退出游戏后上传稳定快照；如果打开 **自动同步：退出 Nemessix 后上传**，菜单栏会检测 Nemessix 从运行变为退出后再上传。
8. **继续本地并打开 Nemessix**：云端不可用、或你明确想先用本地存档时再点。

### 3. Android 端

1. 打开 Android App。
2. 在 **同步到哪里** 填同一个服务器地址。
3. 在 **Android Nemessix 存档目录** 里选择 Nemessix 的共享存档目录。
4. 确认 **MH3G 同步开关** 打开。
5. 启动 MH3G 前点 **启动前检查**。

## 日常怎么用

### 办公室 Mac 玩完，回家 Android 继续

1. Mac 启动 MH3G 前先点菜单栏 **启动前检查**。
2. 如果云端正常且没有更新，继续打开 Nemessix 游玩。
3. 退出 MH3G 后，工具会在安全条件满足后把稳定存档上传到服务器。
4. 回家打开 Android App，点 **启动前检查**。
5. 如果云端有 Mac 的新版本，先选择 **先下载云端到本机缓存（不覆盖）**；确认要恢复时，再选择 **云端覆盖本地（先备份，需停止 Nemessix）**。

### 回家 Android 玩完，回办公室 Mac 继续

当前 Android Alpha 只能配置、授权目录和检查服务器；真实上传、下载、恢复按钮会保持禁用，不能用于完成这一流程。此前显示“后台任务在排队/已完成”不代表存档已经同步。只有 SAF → 稳定快照 → E2EE → server 链路通过真机验收后，下面的目标流程才会启用：启动前检查 → 游戏退出 → 上传稳定快照 → Mac 选择恢复或处理冲突。

## 按钮到底是什么意思

| 按钮 | 实际含义 | 会不会覆盖本地 |
| --- | --- | --- |
| 启动前检查 | 看服务器能不能连、云端有没有 MH3G 版本 | 不会 |
| 同步到服务器（上传本地稳定快照） | 本地存档稳定后，加密上传到服务器 | 不会 |
| 同步到本机缓存（只下载，不覆盖） | 只把云端版本下载到手机/电脑缓存 | 不会 |
| 云端覆盖本地（先备份，需停止 Nemessix） | 先备份当前本地，再把云端版本恢复到模拟器目录 | 会，但只在你确认且模拟器停止后 |
| 本地替换云端（保留云端旧版本） | 用本机稳定存档作为新的云端版本 | 不会覆盖本地；云端旧版本保留 |
| 继续使用本地并打开 Nemessix | 本次不恢复云端，继续玩本地存档 | 不会 |

## 冲突时怎么选

不会按“谁时间新”自动覆盖。

当 Mac 和 Android 都改过同一个 MH3G 存档时，工具会保留两边历史，并让你选择：

- **云端覆盖本地**：你认为云端那份才是要继续玩的版本。
- **本地替换云端**：你认为当前设备上的版本才是要继续玩的版本。
- **暂不处理**：先不改任何一边，等你确认后再说。

Alpha 现在有一个 `mh3g-3ds` 差异解析入口：发生冲突时可以先列出两边不同的文件、文件大小、校验摘要和变更字节段。它能帮你判断“是不是同一份存档文件发生变化”，但当前不声称能看懂猎人名、装备、道具或任务进度；这些必须以后按具体游戏单独做解析器，不能通用猜。

## 云端不可用时怎么办

可以继续使用本地存档，但要明确知道：这次没有同步到服务器。

- 本地原始存档不会因为服务器故障被删除或覆盖。
- 后台会保留待上传任务。
- 服务器恢复后再补传。
- 如果另一台设备期间也玩过，会进入冲突处理，需要你手动选择。

## 当前 Alpha 边界

- 第一阶段中文优先，暂不追求多语言。
- Mac 端现在是菜单栏 App；正式签名安装包和更完整的图形化恢复流程仍在后续阶段。
- Android 不要求 root，不读取其他 App 沙盒；如果没有授权存档目录，会直接停止相关动作。
- 真实多模拟器兼容仍要以 `docs/runbooks/PHASE1_VALIDATION.md` 的验证记录为准；示例和界面演示不能当成真实可用证明。
