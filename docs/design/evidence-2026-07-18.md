HOME and temporary Applications directory, starts that disposable menu-bar
process, and queries its live AX menu-bar boundary through System Events before

current setup state and an accessibility help string containing the next safe
action. statusItemAccessibilityNamesTheCurrentStateAndNextAction guards the
copy contract. macOS ControlCenter reports third-party extras as generic
status menu elements in this host's global tree, so this gate proves the
owned application AX boundary rather than claiming a global ControlCenter
title readback.
